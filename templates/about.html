THE PROJECT

Where AI Meets Healthcare.

Built with the vision of making intelligent brain MRI screening more accessible and understandable.

01

Intelligent Screening

The system analyzes uploaded brain MRI images and uses a trained Deep Learning model to classify the image into tumorous or non-tumorous categories.

02

Transfer Learning

AarogyaDrishti uses VGG19 as the foundation for extracting meaningful visual features from brain MRI images before performing classification.

03

Personalized Reports

Prediction results can be presented through a structured report containing patient information, prediction, confidence and supportive recommendations.

04

Dr. Voice

The platform is designed to provide voice-based explanations in English and Hindi so that screening results can be understood more easily.

HOW IT WORKS

From MRI To Insight.

01
INPUT

Upload MRI

The user uploads a brain MRI image through the prediction interface.

02
PROCESSING

AI Analysis

The image is processed and passed through the trained VGG19-based classification model.

03
RESULT

Prediction

The system provides the predicted class together with its model confidence.

04
ASSISTANCE

Report & Guidance

The result can be presented with recommendations, voice assistance and a structured health report.
